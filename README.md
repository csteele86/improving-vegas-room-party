# Summary
This is a collection of static sites that have been used to invite people to the annual Improving Vegas Room Party!

## Running Tests

This project uses Jasmine for unit testing. To run the tests:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the tests:
   ```bash
   npm test
   ```

The test suite includes comprehensive tests for the background toggle functionality in the 2024 party page.
